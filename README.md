# Tic Tac Toe

A simple Tic Tac Toe game made with HTML, CSS and JavaScript.

## About the project

This project is a browser game for two players.

The game uses a 3x3 board. Players use X and O to play and try to get three marks in a row.

This project is part of my JavaScript practice.
